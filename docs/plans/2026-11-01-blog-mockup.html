#Motivation

Let’s say we have an online store in which the user can add some products to his cart. When the user clicks the “add to cart” button, the first question is: is this user logged in? What if the user is not logged in? And how do we add the product to the cart after login?

Note: this article uses Vue.js and Vuex, but you can implement the idea with your favorite technology.
